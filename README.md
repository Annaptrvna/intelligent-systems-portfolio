## Project: Pirate Intelligent Agent

### Project Overview

In this project, I worked on an intelligent agent that learns to find treasure in a maze. The pirate uses deep Q-learning to learn which actions help it reach the goal.

### What Code Did I Work On?

The starter code included the maze, the game environment, and helper functions. I completed the `qtrain()` function, which trains the agent. I added code to choose actions, save experiences, train the model, and check the agent's progress.
